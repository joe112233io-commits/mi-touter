# 🚀 TutorAI Desktop Platform

> **Next Level AI Tutoring for Life-Long Learners**  
> تطبيق تعليمي تفاعلي متكامل مبني بالكامل على معمارية ومواصفات تقرير **TutorAI** الفنية والهندسية، باستخدام **HTML5 / CSS3 / JavaScript (ES6+)** مع قاعدة بيانات محلية **Realm DB**، ومهيأ للتشغيل والتحويل لتطبيق سطح مكتب باستخدام إطار عمل **Electron**.

## 🌟 أبرز مميزات التطبيق المنفذة من التقرير الفني

1. **محرك توليد المناهج والدورات الفوري (Instant AI Course Generator)**:
   - توليد مسارات تعليمية مخصصة استناداً إلى الهدف والمستوى المعرفي وأسلوب التعلم.
   - تقسيم هرمي احترافي إلى وحدات دراسية (*Modules*) ودروس مركزة (*Lessons*).
   - إمكانية استعراض وتعديل هيكل الدورة قبل بنائها (*Define course structure*).
   - توليد المحتوى عند الطلب (*Lazy Loading*) لتوفير الاستهلاك وتسريع العرض.
   - ميزة القراءة الصوتية للدروس (*Read Aloud / Text-to-Speech*).

2. **بناء الدورات من الوثائق والمصادر الخاصة (RAG System)**:
   - ميزة *Use your own sources* تتيح للمستخدم رفع ملفات PDF و DOCX والملخصات لإنشاء دورة مرتبطة تماماً بمصطلحات ومنهج الوثيقة.

3. **شريط أدوات التعمق التفاعلي داخل الدرس (Go Deeper Toolbar)**:
   - **التبسيط (Simplify)**: إعادة صياغة الدرس بتشبيهات واستعارات من الحياة اليومية.
   - **الأمثلة (Examples)**: توليد 3 أمثلة تطبيقية متدرجة (تأسيسي، بيئة عمل واقعية، تطبيقي متقدم).
   - **الاختبار الفوري (Quiz)**: اختبار تفاعلي فوري من 4 خيارات مع تعليل فوري للإجابات الصحيحة والخاطئة.
   - **البطاقات الذكية (Flashcards)**: استخراج مصطلحات ومفاهيم الدرس وإضافتها لجدولة التكرار المتباعد.
   - **طرح سؤال (Ask a Question)**: درج محادثة سياقي محقون بنص الدرس للإجابة الدقيقة عن أي استفسار.

4. **نظام البطاقات الذكية ولوحة التكرار المتباعد (Spaced Repetition & SM-2)**:
   - بطاقة تفاعلية ثلاثية الأبعاد تنقلب بسلاسة (*3D CSS Flip Card*).
   - تطبيق خوارزمية **SuperMemo SM-2** بالمعادلة الدقيقة لحساب معامل السهولة (*Easiness Factor*):
     $$\text{EF}' = \max(1.3, \text{EF} + (0.1 - (3 - q) \cdot (0.08 + (3 - q) \cdot 0.02)))$$
   - أزرار التقييم الأربعة: *Again (0)*، *Hard (1)*، *Good (2)*، *Easy (3)*.
   - لوحة إحصائيات حية: البطاقات المستحقة للمراجعة اليوم، البطاقات المتقنة، ونسبة الحفظ.

5. **محرك حل المسائل الرياضية الذكي (AI Math Solver)**:
   - منطقة سحب وإفالت أو تصوير المسائل والخط اليدوي (*Photo Math / OCR*).
   - حل متدرج في بطاقات مرقمة (01، 02، 03) تشرح القواعد المطبقة وصيغ LaTeX وتقديم الإجابة النهائية المحددة.
   - تغطية فروع الرياضيات الستة: التفاضل والتكامل، الجبر، الهندسة والمثلثات، الإحصاء والاحتمالات، ما قبل التفاضل، والمسائل اللفظية.

6. **أداة Homeworkify ومدرب الكتابة (Writing Coach)**:
   - حل تفاعلي للواجبات المدرسية مع أسئلة تحقق من الفهم.
   - تدقيق وتقييم المقالات والنصوص وفق معايير الوضوح، البنية، النبرة، والقواعد اللغوية مع نسبة تقييم ومقترحات تحسين.

7. **مكتبة الـ 9 دورات المجانية الجاهزة**:
   - 9 دورات كاملة ومجهزة مسبقاً في قاعدة البيانات المحلية للتصفح الفوري.

8. **نظام التنقل المزدوج (Dual Navigation Architecture)**:
   - **الشريط التسويقي العام**: للصفحة الرئيسية، الأسعار، حل الرياضيات، والمكتبة.
   - **شريط تطبيق مساحة العمل (Workspace App Navbar)**: للدورة الحالية، إنشاء دورة، البطاقات الذكية، المكتبة، والملف الشخصي.

## 🗄️ هيكل قاعدة البيانات المحلية (Realm DB)

تم تطبيق الـ 10 جداول الموثقة في الصفحات 18 إلى 20 من التقرير في المجلد `database/`:
1. `Organization`: بيانات المؤسسات والعلامة البيضاء والنطاق المخصص.
2. `User`: المستخدمين والخطط (*Free*, *Mentor*, *Genius*) وتفضيلات التعلم.
3. `SourceDocument`: المستندات المرفوعة لميزة الـ RAG.
4. `DocumentChunk`: أجزاء الوثائق والتمثيل المتجهي للبحث الدلالي.
5. `Course`: الدورات، نسبة التقدم، ومطالبات التوليد.
6. `Module`: الوحدات الدراسية التابعة لكل دورة.
7. `Lesson`: الدروس ومحتواها التوليدي بصيغة Markdown وصيغ التبسيط والأمثلة.
8. `LessonQuiz`: أسئلة الاختبارات التفاعلية والخيارات والتعليل.
9. `Flashcard`: البطاقات الاستذكارية ومعاملات خوارزمية SM-2 وتاريخ المراجعة.
10. `HomeworkSolution`: سجلات حلول الواجبات والمسائل الرياضية والخطوات.

## 💻 طريقة التشغيل

### أولاً: التشغيل الفوري في المتصفح (Web Preview)
يمكنك تشغيل التطبيق مباشرة في أي متصفح ويب بإحدى الطرق التالية:
1. **النقر المزدوج** على ملف `index.html` لفتحه في متصفحك المفضل (كروم، إيدج، فايرفوكس).
2. أو تشغيل خادم محلي خفيف عبر سطر الأوامر:
   ```bash
   npx serve .
   ```
   ثم فتح الرابط `http://localhost:3000`

### ثانياً: التشغيل كتطبيق سطح مكتب عبر إطار عمل Electron
المشروع مجهز بالكامل بملفات `main.js` و `preload.js` و `package.json`:
1. تثبيت حزم Electron (مرة واحدة):
   ```bash
   npm install
   ```
2. تشغيل التطبيق كنافذة سطح مكتب مستقلة:
   ```bash
   npm start
   ```
3. لتصدير ملف تثبيت تنفيذي لسطح المكتب (Windows `.exe` / macOS `.dmg`):
   ```bash
   npm install
   npm run dist          # بناء حسب نظام التشغيل الحالي
   npm run dist:win      # بناء لـ Windows (nsis + portable)
   npm run dist:mac      # بناء لـ macOS (dmg + zip)
   npm run dist:linux    # بناء لـ Linux (AppImage + deb)
   ```
   تُخرَج الملفات في مجلد `release/` (مستثنى من Git عبر `.gitignore`).
