Frequently Asked Questions

Everything you need to know about TutorAI's multi-provider architecture, security, and free access.

Yes! The TutorAI platform itself is 100% free during the current release—there are no paid subscription tiers or locked features. However, please note the distinction between platform access and external AI provider fees: when you connect your own API key (such as OpenAI, OpenRouter, Anthropic, or your personal Google Cloud Gemini key), that external provider may charge usage fees according to your account plan with them.
TutorAI supports Google Gemini API, OpenRouter, OpenAI API, Anthropic Claude, Groq Cloud, DeepSeek, and any Custom API Provider. Our backend separates protocol adapters cleanly (`openai-compatible`, `gemini-native`, `anthropic-messages`, and `custom-rest`) and verifies every provider with a live connection test before marking it verified.
API keys are never hardcoded or exposed in browser logs. When you save a provider, the key is transmitted to the backend server and encrypted at rest using AES-256-GCM scoped strictly to your user ID. Only a masked preview (e.g., sk-o••••••••9a2f) is returned to the interface.
Course creation saves progress incrementally after each module and lesson. If any lesson fails due to a provider rate limit or temporary timeout, your completed lessons are preserved and you can click "Retry Failed Lessons" or regenerate individual lessons inside the workspace.
